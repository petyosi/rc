# PRP Clarification

Resolve underspecified areas before implementation in the main context.

## Process

1. Read the PRP and apply only taxonomy categories relevant to its scale. Mark them Clear, Partial, Missing, or Deferred and prioritize by `Impact x Uncertainty`.
2. Defer reversible local implementation details to execution. Do not ask questions already answered by repository evidence or the PRP.
3. Group up to three independent high-impact questions in one turn. For each, state the ambiguity, why it matters, the recommended default, and concise tradeoffs. Ask one question at a time only when answers are coupled or the answer changes the next question.
4. Integrate each answer into the authoritative PRP section and append a compact `## Clarifications` record: `- Q: ... -> A: ...`. Do not duplicate the answer across sections.
5. Repeat until high-impact gaps are resolved; report remaining deferred items and recommend execution.

## Early Exit

- If there are no critical gaps, proceed to execution.
- If the PRP is missing, apply the Planning Router and generate a PRP or roadmap.
